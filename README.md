# GRC Security Policies & Compliance Framework

## Project Overview

This academic cybersecurity capstone project focuses on developing information security governance policies and a compliance monitoring framework for **Bento FinTech**, a fictional financial technology organisation.

The project demonstrates practical understanding of Governance, Risk and Compliance (GRC), information security policy development, ISO/IEC 27001:2022 and ISO/IEC 27002:2022 alignment, data protection, and security awareness training.

## Project Objectives

- Establish an information security policy framework.
- Develop data protection and privacy requirements.
- Implement clear desk and clear screen policy guidelines.
- Define compliance monitoring and governance responsibilities.
- Promote security awareness through Wizer training activities.

## Policies and Frameworks Covered

**1. Information Security Policy**

Defines security responsibilities, information asset protection, access controls, risk management and security governance.

**2. Data Protection and Privacy Policy**

Addresses personal data handling, confidentiality, data security and relevant privacy obligations.

**3. Clear Desk and Clear Screen Policy**

Establishes requirements for protecting sensitive information in physical and digital workspaces, referencing ISO/IEC 27002:2022 Control 7.7.

**4. Policy Compliance Framework**

Outlines compliance monitoring, audit responsibilities, policy reviews, escalation procedures and governance oversight.

## Standards and Tools

- ISO/IEC 27001:2022
- ISO/IEC 27002:2022
- UK GDPR considerations
- Wizer Security Awareness Platform
- Security policy documentation
- Compliance monitoring and risk governance
